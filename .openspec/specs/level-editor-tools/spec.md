## ADDED Requirements

### Requirement: Fill Tool Preview
The Level Editor must provide a visual preview of the tile placement when using the Fill tool.

#### Scenario: User drags to define fill area
- **WHEN** the user selects the "Fill" tool
- **AND** selects a tile or tile pattern from the palette
- **AND** clicks and drags the cursor across the canvas
- **THEN** the editor displays a semi-transparent preview of the selected tiles filling the defined rectangular area
- **AND** the preview correctly repeats the selected pattern within the area
- **AND** a boundary outline is displayed around the fill area
